# High Performers Archive

这里存放被团队选中的高表现脚本资产。

建议只归档这三类内容：

1. 创意质量明显高于平均水平
2. 投放数据验证表现优秀
3. 某种 Hook、POV 或情绪结构值得复用

每个归档包建议后续补齐：

- Views
- 3s hold rate
- Completion rate
- CTR
- CVR
- Comment signals
- Creative takeaway

建议不要手动改归档包，优先使用：

```bash
node run.js --updateMetrics tasks/example_metrics.json
```
